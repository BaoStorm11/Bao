# Car Dealership Review Application

A full-stack web application built with **Django** and **React** as part of the IBM Full Stack Developer Capstone Project. The platform allows users to browse car dealerships across different states, view historical reviews, and post new reviews with integrated sentiment analysis.

## Project Architecture
- **Frontend:** React.js, Bootstrap HTML/CSS
- **Backend:** Django Web Framework
- **Database:** SQLite (Django models) / MongoDB (Dealer/Review data)
- **Deployment:** IBM Cloud Code Engine
- **CI/CD:** GitHub Actions

## Features
- User Authentication (Sign Up, Login, Logout)
- View Dealerships and filter by State
- Dynamic review posting with Sentiment Analysis backend
- Responsive UI design for seamless navigation
